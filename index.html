O que é a Tabela ASCII?

Descobrindo como o computador "lê" letras!

Você já se perguntou como um computador entende a letra A ou o número 7? Computadores só entendem números — então precisamos de um "dicionário" que diz qual número representa cada símbolo!

🎯 Analogia: O Código Secreto da Escola

Imagina que você e seus amigos criaram um código secreto onde cada letra tem um número. A = 1, B = 2, C = 3... A Tabela ASCII é exatamente isso, mas para computadores — um código que o mundo inteiro usa!

A sigla ASCII vem do inglês: American Standard Code for Information Interchange — ou seja, um padrão americano de códigos para trocar informações.

📅 Curiosidade histórica

A tabela ASCII foi criada em 1963 e define 128 caracteres — letras, números, pontuação e símbolos especiais. Ela foi tão importante que ainda é a base dos textos digitais até hoje!
